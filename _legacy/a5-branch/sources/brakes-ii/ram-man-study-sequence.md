## Recommended order

1. Start with the force/pressure path and tandem-master drawing.
2. Learn valve functions separately: differential warning, metering,
   proportioning, load sensing, and residual pressure.
3. Work the diagnosis sequence as one isolation ladder rather than four parts
   to memorize.
4. Use excessive pedal travel as a fluid-volume accounting problem.
5. Treat booster tests as assist tests, not hydraulic-system verdicts.
6. Finish with disc conversion as a complete-system matching exercise.
7. Study the stop-light switch last as an electrical/controller input that must
   not disturb mechanical pedal return.

## Minimum lesson checks

After the sequence, be able to answer these without naming a replacement part:

- What observation separates lost assist from excess hydraulic travel?
- What does a higher second pedal press tell you, and what does it not prove?
- If a hot wheel releases when its bleeder is opened, what boundary has been
  isolated?
- How can insufficient master-cylinder pushrod clearance create heat-dependent
  drag?
- What is the difference between a pressure-differential switch and a
  proportioning valve?
- Why can a smaller master-cylinder bore raise pressure but increase travel?
- Which conversion parameters must be matched besides the caliper bracket?
- How can a brake-light-switch adjustment interfere with pedal return?
