# Identify the assist architecture first

Scope: architecture only. Sources: bosch-eps-architecture; zf-ehps-noise.
Bosch's operating principle separates torque input, controller and assist motor,
with column and rack variants. ZF's EPHS article describes an electric motor-pump
feeding a hydraulic gear. Engine-driven hydraulic steering uses a mechanical pump
drive. These distinctions determine which tests have meaning.

An EPS-only car has no hydraulic steering reservoir or pump-pressure test.
An EHPS pump can run independently of engine speed while still using fluid.
An internal EPS belt does not imply a hydraulic pump. Confirm the installed
system through exact service information before selecting a test. Preserve
mechanical binding and tire/load causes in every architecture. No part replacement
or numerical service limit follows from this architecture page.
