# Atomic video sources

Each `youtube-<video-id>.md` file is the canonical record for one video. Do not create a second record because the same video appears in another playlist or coverage bucket; add another membership or coverage value to the existing record.

A `metadata-only` record is intentionally incomplete and must not be indexed as a reviewed summary.

A transcript-reviewed record requires an individual source-grounded note and a
matching [caption provenance receipt](../transcript-reviews.tsv). Retrieval uses
only separately approved passages, not the complete record or raw captions.
`partial` never becomes eligible merely because all available text was read.
Stored-text review does not establish video playback or timed coverage.
